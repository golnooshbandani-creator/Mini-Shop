# Mini-Shop | فروشگاه اینترنتی مینی‌شاپ

یک وب‌سایت فروشگاهی واکنش‌گرا ساخته‌شده با HTML، CSS و JavaScript.

### امکانات
- دریافت و نمایش محصولات از API
- جست‌وجو، فیلتر و مرتب‌سازی محصولات
- افزودن، حذف و تغییر تعداد محصولات در سبد خرید
- محاسبه مبلغ کل سبد خرید
- ذخیره اطلاعات سبد خرید با localStorage
- طراحی واکنش‌گرا برای اندازه‌های مختلف صفحه

### فناوری‌ها
HTML5، CSS3، JavaScript، Fetch API و localStorage
---

A responsive e-commerce website built with HTML, CSS, and JavaScript.
### Features
- Fetch and display products from an API
- Search, filter, and sort products
- Add, remove, and update cart items
- Calculate the cart total
- Persist cart data using localStorage
- Responsive design for different screen sizes

### Technologies
HTML5, CSS3, JavaScript, Fetch API, and localStorage
